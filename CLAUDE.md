# Claude Instructions

Before doing any work in this repository:

1. Read `AGENTS.md` and follow its rules.
2. Read `PROJECT_STATUS.md` to understand the verified project state and open issues.
3. Inspect the current Git branch, working tree, and latest commit.
4. Check the relevant code and tests before proposing a fix.

Treat repository files and current test results as more reliable than assumptions from previous conversations. Do not repeat failed experiments without a new hypothesis. Ask for approval at the checkpoints described in `AGENTS.md`.

At the end of the task, provide a concise report of changes, verification results, and remaining issues. Update `PROJECT_STATUS.md` when important project facts change.
